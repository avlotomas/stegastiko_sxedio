# Implement Spec Section

Use this skill to implement a requirement section end-to-end.

## Steps

1. Read exact section/subsection and list explicit rules.
2. Define model fields/state needed (or reuse existing).
3. Implement form/service validation for each rule.
4. Implement view(s) and templates with Greek labels and section reference.
5. Add stage gates/permission checks as required.
6. Add tests that prove happy path + blocked path(s).
7. Ensure audit history captures all state changes.
8. Update requirement markdown docs with versioned notes.
