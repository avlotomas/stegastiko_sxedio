# Στεγαστικό Σχέδιο · Επαρχία Λευκωσίας

Τοπική, εκτελέσιμη έκδοση εργασίας για την καταχώριση υποθέσεων διάθεσης κρατικών οικοπέδων. Είναι νέο αυτοτελές έργο. Χρησιμοποιεί μόνο Python 3.10+ και SQLite, χωρίς εγκατάσταση πακέτων.

## Εκκίνηση

```bash
cd stegastiko_nicosia
python3 app.py
```

Ανοίξτε στον ίδιο υπολογιστή το **http://127.0.0.1:8765**. Η εφαρμογή ακούει μόνο στην τοπική διεύθυνση. Τερματίζεται με `Ctrl+C`. Για διαφορετική θύρα: `PORT=8766 python3 app.py`.

Η βάση δημιουργείται αυτόματα στο `data/housing.sqlite3`, ενώ τα ανεβασμένα έγγραφα στο `data/uploads/`. Για αντίγραφο ασφαλείας κρατήστε και τα δύο. Το αρχείο ZIP της διανομής περιέχει **κενή** βάση: δεν περιλαμβάνει πραγματικά προσωπικά δεδομένα ή δοκιμαστικές αιτήσεις.

## Ροή καταχώρισης

1. **Υπόθεση κοινότητας:** επιλέξτε μόνο περιοχή του καταλόγου Λευκωσίας. Για νέο αίτημα Κ.Σ. υπάρχουν οι ενότητες 1–8.8. Για αδιάθετα παλαιού διαχωρισμού αρχίστε στην 8.8. Η ίδια κοινότητα μπορεί να έχει περισσότερες από μία ανεξάρτητες υποθέσεις και τις δύο ροές ταυτόχρονα.
2. **Οικόπεδα:** καταχωρίστε κάθε τελικό οικόπεδο στην αντίστοιχη υπόθεση. Απουσία τίτλου, συμπληρώστε τη χωριστή απάντηση/αξία ΤΚΧ ανά οικόπεδο. Η τιμή διάθεσης εμφανίζεται αυτόματα ως 25% της καθορισμένης αξίας.
3. **Γνωστοποίηση:** επιλέξτε τα συγκεκριμένα οικόπεδα, ακόμη και από διαφορετικές υποθέσεις ή κοινότητες. Το πλήθος προκύπτει από τις επιλογές. Ορίστε ημερομηνίες και δημοσιεύστε. Το περιεχόμενο μιας δημοσιευμένης γνωστοποίησης και τα βασικά στοιχεία των προσφερόμενων οικοπέδων δεν τροποποιούνται απευθείας.
4. **Αιτήσεις πολιτών:** μετά τη δημοσίευση παραλάβετε κάθε Παράρτημα 3 ως ξεχωριστή αίτηση για **μία** κοινότητα της γνωστοποίησης. Το ίδιο πρόσωπο μπορεί να αιτηθεί άλλη κοινότητα με δεύτερο αριθμό αίτησης. Ο προκαταρκτικός κατάλογος ενδιαφερομένων του Κ.Σ. είναι ανεξάρτητος.
5. **Έλεγχος:** ανεβάστε το πρωτότυπο σαρωμένο έντυπο, ενημερώστε αργότερα την 10.2.2, τη σύνθεση/τέκνα, τον πίνακα εισοδημάτων και τα επτά κριτήρια της 10.4. Η κατ’ αρχήν εισήγηση προκύπτει από τα κριτήρια. Η Επιτροπή καταχωρίζει χωριστή απόφαση στην 10.5. Η κατανομή της 10.10 ελέγχει κοινότητα, γνωστοποίηση, διαθεσιμότητα και ήδη κατανεμημένο οικόπεδο στο ίδιο πρόσωπο.
6. **Μετά την κατανομή:** καταγράψτε πληρωμή, υπογραφή, αρχική μεταβίβαση και παρακολούθηση στις 10.11–10.12. Η μεταβίβαση μπορεί να προηγείται της ανέγερσης.

Οι καρτέλες **Αρχεία** δέχονται PDF, JPG, PNG ή TIFF έως 20 MB. Το πρωτότυπο διατηρείται ως ανεβασμένο αρχείο. Η καρτέλα **Ιστορικό** εμφανίζει ενέργειες και προηγούμενες εκδόσεις ενοτήτων.

## Έντυπα και περιοχές

Στον φάκελο `templates/` υπάρχουν αυτούσια τα αρχεία που δόθηκαν: Παράρτημα 1, αίτημα Κ.Σ. (Παράρτημα 2), αίτηση πολίτη (Παράρτημα 3), Συμφωνία (Παράρτημα 4), πρότυπο γνωστοποίησης. Είναι διαθέσιμα για λήψη και από την αρχική οθόνη. Ο κατάλογος επιλογών προέρχεται από το Παράρτημα 1 και περιορίζεται στις **102 περιοχές της Επαρχίας Λευκωσίας**.

## Έλεγχοι

```bash
python3 -m unittest discover -s tests -v
node tests/ui_render.cjs
```

Ο πρώτος έλεγχος εκκινεί πραγματικό τοπικό HTTP server με προσωρινή βάση και δοκιμάζει τις δύο ροές, γνωστοποίηση με παλαιά/νέα οικόπεδα, δύο κοινότητες, δύο αιτήσεις του ίδιου προσώπου, τιμή 25%, ιστορικό και απαγόρευση δεύτερης κατανομής. Ο δεύτερος ελέγχει την παραγωγή των βασικών οθονών. Το Node χρειάζεται μόνο για αυτόν τον δεύτερο έλεγχο, όχι για την εφαρμογή.

## Όρια αυτής της έκδοσης

- Είναι πρωτότυπο εσωτερικής αξιολόγησης, χωρίς σύνδεση χρηστών, ρόλους, κρυπτογράφηση ή κεντρική φιλοξενία. Μην καταχωρίσετε πραγματικά προσωπικά δεδομένα πριν υλοποιηθούν οι έλεγχοι πρόσβασης και η εγκεκριμένη υποδομή του Υπουργείου.
- Η σάρωση αποθηκεύει το αρχείο, αλλά η αυτόματη ανάγνωση χειρόγραφων ελληνικών πεδίων και η ανθρώπινη επιβεβαίωση OCR δεν έχουν υλοποιηθεί. Η καταχώριση γίνεται χειροκίνητα.
- Η πολεοδομική ζώνη καταχωρίζεται χειροκίνητα μέχρι να υπάρξει διασύνδεση DTPH. Τα εισοδηματικά όρια δεν ενσωματώθηκαν ως επαληθευμένος επίσημος πίνακας, άρα η τελική κρίση μένει στον λειτουργό και στην Επιτροπή.
- Το Παράρτημα 4 διατίθεται αυτούσιο, **όχι ως αυτομάτως συμπληρωμένο οριστικό συμφωνητικό**. Η διατύπωση για οικόπεδο χωρίς τίτλο και μονογονεϊκή οικογένεια, καθώς και το πρότυπο γνωστοποίησης που μπορεί να περιλαμβάνει παλαιά και νέα οικόπεδα, χρειάζονται νομική οριστικοποίηση πριν παραχθούν έντυπα για υπογραφή ή δημοσίευση.
